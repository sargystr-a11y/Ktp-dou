# КТП ДОУ — прототип сервиса

Сервис формирует черновик календарно-тематического плана на неделю на основе трёх документов ДОУ: шаблона КТП, перспективного плана и картотеки игр. Поддерживаются DOCX, PDF с текстовым слоем, TXT и XLSX. Результат — редактируемый DOCX.

## Запуск

- Python 3.10+
- `pip install -r requirements.txt`
- Установить переменные окружения `AI_API_KEY`, `AI_BASE_URL=https://api.deepseek.com`, `AI_MODEL=deepseek-flash`
- `uvicorn main:app --host 0.0.0.0 --port 8000`

## Render

В репозитории есть `render.yaml`. При создании Web Service добавьте `AI_API_KEY` как Secret/Environment Variable. Ключ нельзя помещать в Git.

## Текущие ограничения

Это пилотный прототип: нет регистрации, личных кабинетов, платежей, подписок и постоянного хранения документов. Форматирование исходного шаблона DOCX не переносится один-в-один. Нет OCR для сканированных PDF. Результат необходимо проверить педагогу/методисту.

До внедрения авторизации, изоляции пользователей, HTTPS, лимитов и политики удаления не загружайте персональные данные детей, сотрудников или конфиденциальные документы. Для тестов используйте обезличенные файлы.
